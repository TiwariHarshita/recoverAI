# RecoverAI

AI-powered revenue recovery agent for Razorpay merchants.

RecoverAI detects revenue at risk, diagnoses payment failures,
predicts the best recovery intervention, checks merchant-defined
guardrails, executes recovery actions, and measures revenue recovered.

## Core components

- FastAPI backend
- PostgreSQL
- Razorpay Test APIs + Webhooks
- CatBoost recovery prediction model
- LangGraph recovery workflow
- React + TypeScript frontend
- Synthetic merchant recovery simulator
